# PCSO Lotto Notifier

- PCSO Lotto Result Checker & Notifier
- Get notified immediately if you win!

- This project automates the checking of your PCSO lotto combinations against the latest official results. Using GitHub Actions, it runs on a schedule, compares your numbers, and sends a push notification directly to your phone via the Pushover API if you hit the jackpot (or any prize!).
